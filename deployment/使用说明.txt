================================================================
NEXUS 引擎 - 使用说明
================================================================

不用懂技术，按顺序点两个文件就行。


----------------------------------------------------------------
第一步：双击 "① 环境检测.bat"
----------------------------------------------------------------

它会检查您这台电脑能不能装。

  · 显示"可以安装"  → 继续第二步
  · 显示"不能安装"  → 把窗口截图发给我们，
                       我们会告诉您怎么解决

这个检查不改动您电脑上的任何东西，只是看一眼。

（下面还有 "③ 开机自启.bat"、"④ 常用工具.bat"、"⑤ 模型切换.bat"，
  那三个是第二步装完以后才用的，现在不用管。）


----------------------------------------------------------------
第二步：双击 "② 一键部署.bat"
----------------------------------------------------------------

它会自动完成安装，大约 5-10 分钟。

过程中会问您一句：

    是否现在下载该模型？[Y/N]

请按 Y 然后回车。

（模型就是让软件能回答问题的大脑，2-9 GB，
  下载时间看您的网速。）


================================================================
关于"模型"是什么（很多人问这个）
================================================================

模型就是这个软件的大脑。没有它，软件不会回答问题。

它需要单独下载一次，之后永久存在您电脑里，
以后断网也能用，不用再下第二次。

   不用去别的地方找，也不用花钱买。
   双击 "② 一键部署.bat" 时，脚本会自动帮您下载。

--------------------------------
但可能要先装一个叫 Ollama 的工具
--------------------------------

模型由 Ollama 负责管理，所以电脑上得先有它。

如果您的电脑没有，脚本会提示：

    未检测到 Ollama
    是否现在打开 Ollama 下载页面？[Y/N]

按 Y，浏览器会自动打开下载页：

  1. 点 Download，下载 OllamaSetup.exe
  2. 双击安装，一路点下一步
  3. 装完重新双击 "② 一键部署.bat"

只有第一次需要这样。以后模型已经在电脑里了，
开机就能直接用。

【说明】Ollama 是免费的，也是这类软件通用的工具，
不是我们另外收费的东西。


================================================================
装完之后
================================================================

1. 浏览器打开：http://127.0.0.1:8085/health
   看到 {"status":"ok"...} 就说明装好了。

2. 用 Cherry Studio 连接到软件：
   接口地址填：http://127.0.0.1:8085/v1
   API 密钥填：123（随便填，本地不验证）
   模型名填：qwen2.5:7b（按实际下载的那个填）

   注意：地址结尾要有 /v1，少写会连不上。


================================================================
开机自动启动（重要）
================================================================

以前每次开电脑都要重新双击 "② 一键部署.bat"，很麻烦。

现在 "② 一键部署.bat" 装完后，
会自动帮您设置好开机自启。设置好之后：

  · 开机后什么都不用做，软件自己就在运行
  · 屏幕上不会出现任何窗口，这是正常的
  · 直接打开 Cherry Studio 就能用

如果想取消自启（或重新开启）：
  双击 "③ 开机自启.bat"，按提示操作即可。


================================================================
日常维护：双击 "④ 常用工具.bat"
================================================================

装好之后，日常的开关、查日志、下模型都在这里，不用记命令。
双击后会看到一个编号菜单：

    [1] 启动服务          [7] 查看已安装模型
    [2] 停止服务          [8] 下载模型
    [3] 重启服务          [9] 导出诊断包（发给技术支持）
    [4] 查看运行状态      [10] 设置/取消开机自启
    [5] 查看日志          [11] 修改端口
    [6] 打开接口文档      [12] 备份配置

最常用的三个：

  · 想关掉软件     → 选 2
  · 软件不响应     → 选 3 重启
  · 发给技术支持   → 选 9，会自动生成"诊断报告.zip"，
                      直接把这个文件发过来就行


================================================================
日志在哪（出问题时很有用）
================================================================

    NEXUS引擎\data\logs\nexus.log

软件是后台运行的，看不到窗口，所以所有记录都写在这里。
出任何问题，把这个文件（或菜单 9 生成的诊断报告）发给我们，
就能快速定位原因。


================================================================
三件要记住的事
================================================================

1. 软件在后台运行，看不到窗口，这是正常的，
   不代表它没启动。

2. 电脑重启后会自动运行，不需要再点任何东西。

3. 默认全部在您自己电脑上运行，不会上传到网上，
   断网也能用。


================================================================
想让回答更快更准？切换模型来源
================================================================

双击 "⑤ 模型切换.bat"，屏幕右侧会出现一个小窗口，
上面三个按钮，点一下就切换：

    [本地]  只用自己的电脑，绝不联网。
            最安全，速度看您电脑配置。

    [自动]  优先用本地；本地模型没准备好时，
            自动改用云端 API。（推荐）

    [API]   始终用云端 API。效果最好，但需要联网，
            而且回答内容会发到外部服务商。


小窗口可以拖动，会一直浮在最上层，
点右上角 X 关掉。


----------------------------------------------------------------
用 API 之前要先填一次密钥
----------------------------------------------------------------

在同一个窗口下方有"API 设置"，填三项后点"保存并启用"：

    服务地址   例如 https://api.deepseek.com/v1
    模型名     例如 deepseek-chat
    API 密钥   sk- 开头，找服务商申请

密钥只存在您电脑的 data\cloud.key 文件里，
不会写进配置文件，也不会出现在诊断包里。


----------------------------------------------------------------
怎么知道现在用的是哪个？
----------------------------------------------------------------

小窗口标题右侧显示"本地"或"API"，
下面一行显示正在用的模型名。

如果显示"未就绪"，说明本地模型还没装好，
用 "④ 常用工具.bat" 选 8 下载模型即可。


----------------------------------------------------------------
遇到问题
----------------------------------------------------------------

把出错窗口截图发给我们，
说明当时正在做什么操作。

不要自己尝试修改或删除文件，
那可能让问题更难排查。
